All AI-generated code was reviewed, tested, and adjusted before inclusion:
- The initial implementation used Flask-SQLAlchemy and Flask-Login, which conflicted with the team's existing raw SQLite structure. This was identified and fully rewritten to match the team's `db.py` approach.

- Route endpoint names were corrected after CI pipeline errors revealed mismatches between blueprint names and `url_for()` calls in templates.
- SQL queries were reviewed to ensure parameterized inputs and correct JOIN behaviour for report and user queries.
