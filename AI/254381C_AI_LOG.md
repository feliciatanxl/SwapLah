I declare that I have used Artificial Intelligence (AI) tools to assist in the development of this assignment in the following ways:

3. **Debugging & Layout Fixes:** Used AI to troubleshoot responsive flexbox layout issues, spacing discrepancies, navbar alignment issues, footer spacing issues, and inconsistent layout behaviour across different screen sizes.

4. **Frontend Redesign Refinement:** Used AI assistance to refine the SwapLah static frontend design based on the Figma Make reference. 5. **Authentication Page Design:** Used AI assistance to create and refine the Login, Register, and Forgot Password pages. The pages were redesigned with a consistent split-layout style, dark navy branding panels, orange call-to-action buttons, NYP email helper text, and placeholder areas for validation, session expiry, and suspended account messages.

6. **Responsive Layout and Spacing Fixes:** Used AI assistance to troubleshoot and manually refine spacing issues, including navbar-to-content gaps, footer spacing, authentication page panel alignment, homepage section spacing, and responsive behaviour. I reviewed the generated CSS and made manual adjustments where needed to ensure the layout was more presentable and responsive.

7. **Homepage and Navigation Improvements:** Used AI assistance to refine the homepage hero section, Shop by Category cards, Latest Listings filter/search area, listing cards, navbar, and footer. The navbar search was removed to reduce duplicate search areas while keeping the homepage hero search and listings filter/search section.

8. **Git Workflow Guidance:** Used AI assistance to understand Git remote and push behaviour, especially the difference between pushing to GitHub and pushing to the school GitLab repository. I reviewed the commands before using them and remained responsible for committing and pushing the final code.
