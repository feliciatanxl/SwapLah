## Details of Usage

I declare that I have used Artificial Intelligence (AI) tools to assist in the development of this assignment in the following ways:

1. **Backend API Development:** Used AI assistance to plan and implement the item listing creation backend logic, including the `POST /api/listings` route, request handling, required field validation, price validation, login session checking, and JSON response formatting.

2. **Database Implementation:** Used AI assistance to structure the `listings` database table and related database helper functions, including `create_listing()` and `get_all_listings()`. This helped ensure that each listing stores a unique ID, seller ID, title, description, price, category, condition, image data, listing date, and last modified timestamp.

3. **Frontend Form Connection:** Used AI assistance to connect the Sell page form to the backend API using JavaScript `fetch()`. This included converting form input into JSON data, handling successful and failed API responses, and displaying appropriate success or error messages to the user.

4. **Input Validation:** Used AI assistance to improve form and backend validation. This included required field validation, price type validation for numeric price, Free, and Swap Only, and stricter price checks to prevent invalid values such as text, negative numbers, or overly long decimal values.

5. **Image Upload and Preview Feature:** Used AI assistance to enhance the listing form from a simple image URL field into a multiple image upload feature. This included image preview, image slider controls, remove image functionality, and saving multiple images as JSON data while displaying the first image on the homepage listing cards.

6. **Homepage Listing Display:** Used AI assistance to update the homepage so that newly created listings are displayed from the database instead of only using hardcoded sample listings. AI was also used to add image slider functionality to listing cards so users can view multiple uploaded images.

7. **Save Draft Feature:** Used AI assistance to implement a Save Draft feature using browser `localStorage`, allowing users to temporarily save their listing form data and reload it when returning to the Sell page. I reviewed and tested the feature before keeping it in the project.

8. **Debugging and Troubleshooting:** Used AI assistance to troubleshoot issues such as incorrect Flask routes, wrong form submission behaviour, duplicate Flask servers running, missing blueprint registration, merge conflicts, session/login issues, 400 validation errors, 401 unauthorised errors, and JavaScript placement errors.

9. **API Testing Guidance:** Used AI assistance to plan and carry out positive and negative API testing using Postman. This included testing successful listing creation, missing required fields, invalid prices, long decimal prices, and unauthorised listing creation when the user is not logged in.

10. **Unit Testing and Coverage:** Used AI assistance to create and refine unit tests for the listing feature. The tests covered successful listing creation, Free and Swap Only price types, missing fields, invalid price, long decimal price, invalid request body, and unauthenticated user access. The final test run passed with 16 tests and achieved above the required 60% coverage.

11. **Git Workflow Guidance:** Used AI assistance to understand and carry out Git workflows, including creating a feature branch, fetching remote branches, merging the updated `develop` branch, handling merge conflicts, testing another teammate’s login branch locally, committing code, and preparing the branch for a Merge Request.

12. **AI Usage Documentation:** Used AI assistance to refine this AI Usage Declaration so that the tools used, areas of assistance, and my responsibility for reviewing and testing the generated work are clearly documented.
