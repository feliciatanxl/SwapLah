## Example 1: Price Validation

**Initial AI Suggestion:**

```python

    return {"error": "Price is required"}, 400
```

**Issue Identified:**

The initial suggestion only checked whether the price was empty. It did not verify whether the value was numeric, negative, contained excessive decimal places, or matched `Free` or `Swap Only`.

**Refined Implementation:**

* Accept `Free` and `Swap Only`.
* Accept valid non-negative numeric values.
* Reject negative values.
* Reject invalid text.
* Reject numeric values with excessive decimal places.
* Return a clear validation error message.

## Example 2: Listing Ownership

**Initial AI Suggestion:**

Hide the Edit and Delete buttons when the logged-in user is not the listing owner.

**Issue Identified:**

Frontend controls alone are insufficient because another user could directly call the edit or delete API endpoint.

**Refined Implementation:**

* Hide the Edit and Delete buttons for non-owners.
* Retrieve the listing in the backend.
* Compare the logged-in user ID with the listing seller ID.
* Return an unauthorised response if the IDs do not match.

## Example 3: Listing Deletion

**Initial AI Suggestion:**

```sql
DELETE FROM listings WHERE id = ?
```

**Issue Identified:**

The assignment requires soft deletion, so permanently deleting the database row would not satisfy the requirement.

**Refined Implementation:**

```sql
UPDATE listings
SET status = 'Deleted',
    last_modified_timestamp = ?
WHERE id = ?
```

The browse, search, filter, and listing detail queries were also checked to ensure that deleted listings were excluded from normal users.

## Example 4: Search Query

**Initial AI Suggestion:**

Construct the SQL search query by directly inserting the user's keyword.

**Issue Identified:**

Direct string construction could expose the application to SQL injection.

**Refined Implementation:**

```python
search_value = f"%{keyword}%"
cursor.execute(
    """
    SELECT *
    FROM listings
    WHERE status = 'Active'
      AND (title LIKE ? OR description LIKE ?)
    ORDER BY listing_date DESC
    """,
    (search_value, search_value),
)
```
